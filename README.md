# VANGUARD Contracts

Machine-readable architectural contracts and compatibility rules for the VANGUARD system.

## Status

This repository is an implementation incubator. Creating or changing a contract does not by itself establish architectural truth.

Adoption requires explicit evidence and confirmation.

## Governing principle

> Probability may enter the loop, but it does not leave the loop as truth without confirmation.

## Initial scope

- Contract identity and versioning
- API and behavior contracts
- Compatibility declarations
- Integration constraints
- Machine-readable sources of truth
